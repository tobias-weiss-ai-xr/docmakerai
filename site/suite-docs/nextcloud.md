# Files (Nextcloud)

[Nextcloud](https://nextcloud.openedusuite.org) is the classic
cloud in the openEduSuite: sign in via the portal tile
**Files (Nextcloud)** and SSO — the dashboard opens with your
files, shares, and the activity feed.

![Nextcloud dashboard after SSO login](./assets/nextcloud.png)

- **Files** — upload, organize in folders, share with a link or
  with suite members; shared items show who did what in the
  activity feed.
- **Apps** — Nextcloud brings its own app store surface: talk,
  calendar, and more live *inside* Nextcloud. The suite has its
  own dedicated services for those — see below.

## Nextcloud or OpenCloud

The suite runs two clouds, on purpose:

- **[OpenCloud](/suite/files)** — the suite's native file service;
  tightly integrated with the other tiles. First choice for
  everyday files.
- **Nextcloud** — the mature all-rounder with its own app
  ecosystem. First choice when you need a Nextcloud-specific app
  or are used to its workflows.

Both use the same SSO account; files live separately in each.

## Accessibility

| Action | Key |
|--------|-----|
| Move through the file list and toolbar | `Tab` |
| Open the focused file or folder | `Enter` |

- The file area is a standard list with a toolbar — `Tab` walks
  it, `Enter` opens.
- `Ctrl+Home` (German keyboards: `Strg+Pos1`) returns you to the
  top of the page.
