# Dateien (Nextcloud)

[Nextcloud](https://nextcloud.openedusuite.org) ist die klassische
Cloud in der openEduSuite: Anmeldung über die Portalkachel
**Dateien (Nextcloud)** und SSO — das Dashboard öffnet mit
Dateien, Freigaben und dem Aktivitätsstrom.

![Nextcloud-Dashboard nach SSO-Anmeldung](./assets/nextcloud.png)

- **Dateien** — hochladen, in Ordnern ordnen, per Link oder mit
  Suite-Mitgliedern teilen; bei Freigaben zeigt der
  Aktivitätsstrom, wer wann was getan hat.
- **Apps** — Nextcloud bringt eine eigene App-Welt mit: Talk,
  Kalender und mehr leben *innerhalb* von Nextcloud. Für all das
  hat die Suite eigene Dienste — siehe unten.

## Nextcloud oder OpenCloud

Die Suite betreibt zwei Clouds, absichtlich:

- **[OpenCloud](/suite/files)** — der native Dateidienst der
  Suite, eng mit den anderen Kacheln verzahnt. Erste Wahl für
  Alltagsdateien.
- **Nextcloud** — der ausgereifte Allrounder mit eigenem
  App-Ökosystem. Erste Wahl, wenn Sie eine bestimmte
  Nextcloud-App brauchen oder ihre Arbeitsweisen gewohnt sind.

Beide nutzen dasselbe SSO-Konto; die Dateien liegen getrennt in
jeder Cloud.

## Barrierefreiheit

| Aktion | Taste |
|--------|-------|
| Durch Dateiliste und Werkzeugleiste bewegen | `Tab` |
| Fokussierte Datei oder Ordner öffnen | `Enter` |

- Der Dateibereich ist eine gewöhnliche Liste mit Werkzeugleiste —
  `Tab` führt hindurch, `Enter` öffnet.
- `Strg+Pos1` bringt Sie zum Seitenanfang zurück.
