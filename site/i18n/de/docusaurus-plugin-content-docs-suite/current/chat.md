# Chat (Element)

Der openEduSuite-[Chat](https://chat.openedusuite.org) läuft auf
[Element](https://element.io) — einem Messenger auf dem offenen
Matrix-Netzwerk. Melden Sie sich mit Ihrem openEduSuite-Konto an und
Sie stehen direkt im Messenger: Räume für Kurse, Arbeitsgruppen oder
Einzelgespräche, auf jedem Gerät.

![Erstanmeldung: Identität bestätigen](./assets/chat-firstlogin.png)

## Erstanmeldung: Identität bestätigen

Bei der ersten Anmeldung auf einem neuen Gerät bittet Element Sie, Ihre
**Identität zu bestätigen** („Bestätige deine Identität" — das
Element der Hochschule spricht Deutsch). Dieser Schritt richtet die
Verschlüsselung ein, die Ihre Nachrichten schützt:

- **Nimm ein anderes Gerät** — der empfohlene Weg, wenn Sie Element
  schon woanders nutzen: das andere Gerät bestätigt das neue, und Ihr
  Nachrichtenverlauf bleibt erhalten.
- **Bestätigung nicht möglich?** — überspringt die Verifizierung,
  allerdings zu einem Preis, den die App vor dem Fortfahren klar
  benennt: Kontodaten, Kontakte, Einstellungen und Chat-Listen bleiben
  erhalten, aber **der serverseitige Verlauf geht verloren**, und alle Geräte und Kontakte
  müssen neu verifiziert werden. Bestätigen Sie mit **Fortfahren**
  nur, wenn Sie nichts verlieren können — etwa auf einem frischen
  Konto.

Nutzen Sie den Chat ernsthaft, verifizieren Sie beim ersten
gelegenen Moment sauber auf einem zweiten Gerät — eine ehrliche
Minute schlägt einen verlorenen Verlauf.

## Der Messenger

Drinnen funktioniert Element wie jeder moderne Messenger: Räume in der
linken Spalte, das Gespräch rechts, das Eingabefeld unten. Legen Sie
Räume für Ihre Arbeit an, treten Sie denen Ihrer Kurse und Kollegen
bei und behalten Sie Ihre Benachrichtigungen im Blick.

Element verschlüsselt von Haus aus: Was Sie schreiben, bleibt zwischen
Ihnen und Ihren Räumen — auch vor den Serverbetreibern, sobald die
Geräte verifiziert sind.

## Barrierefreiheit

| Aktion | Taste |
|--------|-------|
| Durch Räume und Nachrichten bewegen | `Tab` |
| Fokussierte Nachricht senden | `Enter` |

- Der Messenger ist mit der Tastatur erreichbar: `Tab` bewegt Sie
  durch Räume und Gespräch, `Enter` sendet, was Sie geschrieben
  haben.
- Verlieren Sie die Orientierung, bringt Sie `Strg+Pos1` zum
  Seitenanfang zurück.
