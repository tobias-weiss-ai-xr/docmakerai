Wie diese Dokumentation entsteht

Jede Anleitung beginnt als echte Playwright-Aufzeichnung der SOGo-Oberfläche. DocMaker AI kommentiert jeden Schritt, prüft die Aufnahmen auf Qualität und setzt sie zu animierten Illustrationen zusammen — so sehen Sie immer genau, was Sie klicken, eingeben und erwarten können. Mehr über die Pipeline oder einen Fehler melden? Besuchen Sie das Projekt auf GitHub oder sogo.nu.
