How this documentation is made

Every tutorial starts as a real Playwright recording of the SOGo UI. DocMaker AI annotates each step, checks the captures for quality, and assembles them into animated illustrations — so you always see exactly what to click, type and expect. Want to know more about the pipeline, or report an issue? Head over to the project on GitHub or visit sogo.nu.
